# Manuscript support package

This directory collects the version-controlled material needed for a GigaScience
Technical Note. The final submission should use the journal template and cite an
immutable software DOI, DANDI accession/version, benchmark records, and any
associated GigaDB or Code Ocean record.

Required manuscript sections include Background, Methods, Results, Discussion,
Availability of Source Code and Requirements, Data Availability, Competing
Interests, Funding, Author Contributions, and References.
