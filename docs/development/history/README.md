# Historical design material

The `NeuroFlow_*` design documents in this directory are retained as
development history. They informed the implementation but are not the canonical
user guide and may discuss plans rather than shipped behavior — some describe
modules and APIs that were never built or have since been removed. Current
behavior is defined by `getting-started.md`, `concepts.md`,
`High_Level_API.md`, `limitations.md`, `reproducibility.md`, the generated API
reference, and tests.

This index prevents their presence from being mistaken for a second current
architecture contract.
