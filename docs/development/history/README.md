# Historical design material

The root-level `NeuroFlow_*` design documents are retained as development
history. They informed the implementation but are not the canonical user guide
and may discuss plans rather than shipped behavior. Current behavior is defined
by `getting-started.md`, `concepts.md`, `High_Level_API.md`, `limitations.md`,
`reproducibility.md`, the generated API reference, and tests.

They remain in their original locations for stable links; this index prevents
their presence from being mistaken for a second current architecture contract.
